### We build to find out.

Xylo Labs is an independent product lab. We design, build and ship experiments: products, startups, developer tools, AI and other ideas for the internet.

Each experiment gets a number. Some become products, some become companies, and some just teach us something.

## Experiments

| No. | Name | What it is | Status |
| :-- | :--- | :--------- | :----- |
| 001 | [**Xylo**](https://www.xylolabs.space/experiments/xylo) | Stablecoin infrastructure for African markets. USDC settlement on Base, local fiat rails and a developer API. | Building · prototype |
| 002 | [**eETB**](https://www.xylolabs.space/experiments/eetb) | The Ethiopian birr, onchain. A stablecoin on Ethereum, designed to be pegged 1:1 to ETB. | Experiment |

> Both are early. Neither is available for production use, and eETB's reserves aren't in place yet. Nothing here is financial advice or an offer of financial services.

## What we're interested in

- **Products**: small, sharp software that people keep open.
- **Startups**: experiments with enough pull to deserve a company.
- **AI**: software that does the work instead of describing it.
- **Developer tools**: the things we wish existed while building everything else.
- **Web3**: onchain rails, where they beat the old ones.
- **Internet experiments**: odd ideas that only make sense online.
